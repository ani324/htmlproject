# Image Display Webpage

A simple responsive webpage created using HTML and CSS that displays an image along with an interactive button.

# Features

- using viewport
- Responsive design using vw and vh units.
- Image displayed inside a container.
- Interactive button with gradient background.
- use of box-sizing properties.

# Technologies Used
- HTML5
- CSS3
